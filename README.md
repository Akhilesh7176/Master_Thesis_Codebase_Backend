# Traffic_simulation_backend developed with Django

Installation Steps

Open VS Code
Open Master_Thesis_frontend folder
Open the terminal
Install node js with package installer
https://nodejs.org/en/download/prebuilt-installer

Check versions of node and npm
Execute the start command
Bash start_server.sh --v0, --T,--s0 gap,--a A,--b B,--fol FOL
Visualization should start

Open VS code
Open Master_Thesis_backend folder
Open the terminal for python version
Pip3 install Django

If throws errors
Pip3 install Django-cors-headers
pip3 install djangorestframework

To start the server
Python3 manage.py runserver
